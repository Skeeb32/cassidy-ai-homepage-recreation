# Cassidy AI landing page recreation

A responsive, no-build recreation of the Cassidy AI homepage at [cassidyai.com](https://www.cassidyai.com/). The page includes an interactive product preview, responsive navigation, solution carousel, FAQ disclosures, and demo form previews.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. There are no build dependencies.

The imagery is loaded from Cassidy's public Webflow CDN. The demo form is presentational and does not submit visitor data.
